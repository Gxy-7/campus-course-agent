# 数据结构实验指导

课程：数据结构（CS101）
适用学期：2026-2027 学年第一学期
授课教师：张老师

## 一、实验安排

### 实验一 线性表

实验内容：实现顺序表和单链表，完成插入、删除、查找和遍历操作。

实验要求：

1. 实验前必须预习线性表的基本操作，并提交预习报告。
2. 实验课需要携带笔记本电脑，提前安装 Python 3.11。
3. 实验过程中独立完成代码，不允许直接复制同学代码。
4. 实验结束后提交源代码和实验报告。

### 实验二 二叉树

实验内容：实现二叉树的先序、中序、后序遍历，以及二叉树深度计算。

实验要求：

1. 使用递归和非递归两种方式实现遍历。
2. 提交完整源代码、运行截图和实验报告。
3. 实验报告需要分析时间复杂度和空间复杂度。

### 实验三 图

实验内容：实现图的邻接矩阵和邻接表，完成深度优先搜索和广度优先搜索。

实验要求：

1. 两人一组完成，组内分工需要写入实验报告。
2. 实现无权图最短路径计算。
3. 提交代码、测试用例和实验报告。

## 二、提交规范

实验报告统一使用 PDF 格式，文件命名为“学号-姓名-实验序号.pdf”。
源代码打包为 zip 文件，与实验报告一起提交到课程平台。
迟交一天扣 10 分，迟交超过三天按零分处理。

## 三、考核方式

课程总评成绩由三部分组成：

- 平时成绩：20%
- 实验成绩：30%
- 期末考试：50%

期末考试重点考察线性表、树、图、排序和查找。实验报告和代码质量会计入实验成绩。

## 四、学术规范

禁止抄袭、代做和伪造实验数据。发现学术不端行为，本次实验成绩按零分处理，并按照学校相关规定上报。
