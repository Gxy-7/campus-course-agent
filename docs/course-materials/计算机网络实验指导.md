# 计算机网络实验指导

课程：计算机网络（CS102）
适用学期：2026-2027 学年第一学期
授课教师：李老师

## 一、实验安排

### 实验一 网络抓包与协议分析

实验内容：使用 Wireshark 抓取并分析 HTTP、TCP 和 DNS 报文。

实验要求：

1. 实验前安装 Wireshark，并预习 TCP/IP 协议栈基本概念。
2. 只允许抓取自己实验环境中的流量，禁止抓取公共网络中的他人隐私数据。
3. 提交 pcap 抓包文件和分析报告。
4. 报告中需要标注三次握手、四次挥手的位置。

### 实验二 TCP 客户端与服务器

实验内容：使用 Python socket 编写 TCP 客户端和服务器，实现简单聊天功能。

实验要求：

1. 服务端监听 9000 端口。
2. 支持多个客户端连接，并能广播消息。
3. 提交源代码、运行截图和实验报告。
4. 实验报告需要说明 TCP 与 UDP 的区别。

### 实验三 静态路由配置

实验内容：使用 Cisco Packet Tracer 完成三台路由器的静态路由配置。

实验要求：

1. 画出网络拓扑图并标注 IP 地址。
2. 配置完成后使用 ping 和 tracert 验证连通性。
3. 提交拓扑文件、配置命令和实验报告。

## 二、提交规范

实验报告统一使用 PDF 格式，文件命名为“学号-姓名-实验序号.pdf”。
抓包文件、源代码和拓扑文件打包为 zip 提交。
实验报告必须包含实验目的、实验步骤、实验结果和问题分析。

## 三、考核方式

课程总评成绩由三部分组成：

- 平时成绩：20%
- 实验成绩：30%
- 期末考试：50%

期末考试重点考察网络分层、TCP/IP、路由、HTTP 和网络安全基础。

## 四、实验注意事项

1. 实验课需要携带电脑，提前安装 Wireshark 和 Python 3.11。
2. 不允许在校园公共网络中进行端口扫描和流量攻击。
3. 实验中出现问题先查看日志，再向助教求助。
